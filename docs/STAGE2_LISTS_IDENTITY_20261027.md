## Изменения

- В API визитов, клиентов и напоминаний добавлены нумерованные страницы и курсорная загрузка с `total`, `hasNext`, `nextCursor`. Формат массива для старого APK сохранён.
- Новые страницы сортируются по неизменяемым `createdAt` и `id`, чтобы обновление статуса не перемещало запись за уже прочитанную границу курсора.
- Web получает страницы по 50 записей и сохраняет поиск/статус в переходах назад/далее. Общий счётчик относится ко всей выборке.
- Android загружает все курсорные страницы; ошибка одной из страниц не выдаётся за успешную неполную синхронизацию. Повторяющийся курсор останавливает цикл с ошибкой.
- Новая серверная сводка агрегирует всю базу мастерской. Завершённые согласованные работы учтены в воронке. Согласованная стоимость не называется полученной выручкой.
- Главная показывает ограниченное число карточек с переходами к полным спискам, но полные счётчики. Среди ближайших напоминаний и в счётчике меню учитываются только PENDING.
- Повторная приёмка Android передаёт ID выбранных клиента и автомобиля. Изменение названия не создаёт автомобиль; изменение существующего визита сохраняет связанный ID.
- Сервер находит старые форматированные телефоны и нормализует новые. Неоднозначные старые дубли требуют явного выбора, без удаления/объединения истории.
- Номера нормализуются по регистру, разделителям и визуально одинаковым буквам. Поиск учитывает комбинации кириллицы/латиницы старых номеров.
- Выбор чужого ID или несовпадение телефона отклоняется; транзакция не сохраняет частичные изменения.

## Приёмка

- Все 437 синтетических визитов доступны на страницах и через курсор, без потерь/повторов при одинаковых датах и изменении updatedAt.
- Поиск/фильтр сохраняются при переходе между страницами.
- Старое выполненное согласование за пределами первой страницы учитывается в сводке и стоимости.
- Отменённые напоминания видны в журнале, но отсутствуют среди ближайших.
- Один телефон в разных форматах и один номер с другой подписью модели не создают новых карточек.
- При существующих неоднозначных дублях появляется понятное сообщение и возможность явного выбора.
- Выбор клиента/автомобиля другой мастерской отвергается, побочные записи не сохраняются.
