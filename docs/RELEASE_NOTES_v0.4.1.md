# AutoService v0.4.1

Дата выпуска: 19 сентября 2026.

Исправлена production-конфигурация MinIO из v0.4.0: `minio-init` сначала проверяет
наличие отдельного сервисного пользователя и создаёт его только при первом запуске.
Повторный `docker compose up` больше не зависит от поведения команды создания уже
существующего пользователя. Состав приложения, миграции и контракт API не менялись.
