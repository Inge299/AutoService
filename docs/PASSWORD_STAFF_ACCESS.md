# Вход сотрудников и администраторов

Все сотрудники мастерской, включая администраторов, входят по логину и паролю
в Android или веб-кабинет. Роль определяет доступные действия, а не устройство.

При создании пользователя обязательны имя, логин и временный пароль (8–256 символов).
Телефон необязателен; пустое значение не резервирует номер. При первом входе пользователь
обязан установить собственный пароль (12–256 символов). До этого сервер запрещает
рабочие API. Android сохраняет признак обязательной смены в зашифрованной сессии
и показывает форму смены вместо рабочего пространства.

При сбросе пароля администратором активные сессии пользователя отзываются. Новый
временный пароль также требует смены. SMS.RU/SMSC остаются дополнительными
серверными провайдерами; основной парольный вход не зависит от их доступности.

Initial seed запускается только если в базе ещё нет активного администратора.
Обновление существующей установки не восстанавливает удалённые тестовые аккаунты
из BOOTSTRAP_USERS_JSON и не создаёт дополнительного bootstrap-администратора.

## Mia после очистки

Рабочая база очищена отдельно от выпуска этого изменения. Сохранены пользователь
administrator, его членство и настройки мастерской, история миграций. Остальные
пользователи, клиентские данные, визиты, согласования, отчёты, задания, сессии и медиа
удаляются только после backup. Архивы backup остаются для восстановления.

До развёртывания нового seed старый релиз v0.4.2 запускают с дополнительным файлом
`/opt/autoservice/no-reseed.override.yaml`, который отключает initial seed:

```bash
docker compose -p autoservice --env-file /opt/autoservice/.env \
  -f /opt/autoservice/current/docker-compose.deploy.yml \
  -f /opt/autoservice/no-reseed.override.yaml up -d --no-build
```

При следующем выпуске новый seed самостоятельно сохранит единственного администратора.
Тестовые телефоны, ключи, хеши и дампы не включаются в Git.
