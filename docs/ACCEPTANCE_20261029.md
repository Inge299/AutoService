## SMS.RU

Пользователь указал номер для одного тестового SMS. Выполнена одна попытка отправки; приложение вернуло `invalid_response`, подтверждения приёма/доставки нет. Ключ принят, баланс доступен. Запрос стоимости с теми же параметрами, без отправки, вернул ошибку получателя 204: оператор не подключён на отправителе/отправителе по умолчанию. Необходимо проверить раздел «Отправители» в SMS.RU. Повторных отправок не выполнялось.

В обработчике найдена ошибка: Zod допускал только `status=OK`, поэтому документированные ответы `ERROR` теряли числовой код. Обработчик теперь разбирает оба статуса, сохраняет код ошибки запроса или конкретного получателя, не отбрасывает успешный результат из-за ошибки другого получателя и не принимает отказ запроса за успех. Необработанный ответ провайдера, телефон, текст и ключ в сообщение ошибки не включаются.

Проверки изменения: Server typecheck/build и 146 тестов с PostgreSQL, без пропусков. Новые регрессии проверяют коды отказа 204/207/220, ошибку авторизации 200 для отправки и статуса, смешанный ответ, ошибку проверки статуса и некорректный ответ.

Документация провайдера: https://sms.ru/api/send и https://sms.ru/api/cost.
