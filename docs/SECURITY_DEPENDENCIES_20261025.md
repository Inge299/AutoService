# Исправление зависимостей перед развёртыванием — 25 октября 2026

Обновление подготовлено поверх объединённого `main` (`30e0bb5`).
Функции приложения, оформление, схема БД и настройки production не меняются.

## Что обновлено

- Next.js и eslint-config-next: 16.3.5 → 16.4.3.
- Fastify: минимальная версия 5.12.7; Zod: минимальная версия 4.6.7.
- Vitest: 4.1.11 → 4.1.12.
- Lock-файлы обновлены совместимыми исправлениями транзитивных зависимостей,
  включая sharp 0.35.5, source-map-js 1.2.2 и fast-uri 3.1.9 / 4.2.3.
- Prisma остаётся 6.12.0; React и React DOM остаются 19.2.8.

Next.js Server Actions используются приложением, поэтому DoS из
[GHSA-p3m5-59mp-jv5r](https://github.com/vercel/next.js/security/advisories/GHSA-p3m5-59mp-jv5r)
нельзя считать неприменимым. Новая версия также устраняет предупреждения аудита
для других функций Next.js; обнаружение пакета в аудите само по себе не означает
эксплуатируемость всех перечисленных сценариев в AutoService.

## Проверки

- `npm audit --audit-level=high`: 0 уязвимостей в обоих пакетах, включая dev-зависимости,
  по состоянию на дату проверки. Это не гарантия отсутствия неизвестных проблем.
- Server: 80 тестов пройдено, 1 интеграционный тест требует PostgreSQL и пропущен локально;
  генерация Prisma Client, typecheck и build проходят. PostgreSQL-проверки выполняются CI.
- Web: lint, 4 регрессионных теста подключения поиска/медиа, typecheck и production build проходят.
- Локальный standalone-сервер (как в Docker): страницы входа сотрудника и клиента,
  PNG-логотип и его обработка Image Optimization возвращают 200; `/visits` без сессии
  возвращает 307 на вход. Тестовый сервер после проверки остановлен.
- CI для Server и Web теперь блокируется при high/critical предупреждениях `npm audit`.

## Развёртывание

До одобрения и слияния исправления Mia остаётся на прежней версии v0.4.2.
Резервная копия перед обновлением уже создана и проверена:
`/opt/autoservice/backups/pre-main-20261025-30e0bb5`.
Подготовленные образы `:30e0bb5` содержат старые зависимости и не должны
использоваться для окончательного переключения. После слияния нужны новые образы
из нового коммита `main`; схема БД и секреты остаются прежними.
