# Результат полевой проверки Android offline spike

**Дата:** 7 сентября 2026  
**Устройство:** realme RMX3242 (RE513CL1), Android по данным ADB  
**Сборка:** `0.1.0-spike`, debug APK

## Подтверждённые сценарии

| Сценарий | Результат |
|---|---|
| Холодный запуск приложения | пройден |
| Создание визита без ожидания сети | пройден |
| Сохранение визита после `force-stop` и холодного запуска | пройден |
| Открытие CameraX на устройстве | пройден |
| Локальная фиксация фото | пройден |
| Фоновая доставка фото при наличии сети | пройден |
| Фото в авиарежиме → `force-stop` → возврат сети → запуск приложения | пройден |
| Доставка офлайн-фото без ручного повтора | пройдена |
| Совпадение SHA-256 локального и подтверждённого объекта | пройдено |

В финальном сценарии локальная очередь содержала пять файлов, а каталог подтверждённых объектов — четыре. После возврата сети и запуска приложения каталог подтверждённых объектов автоматически вырос до пяти. Размер последнего фото в обеих копиях составил 3 566 701 байт, SHA-256 совпал.

## Ограничения проверки

- В spike сервер моделируется `LocalMirrorUploadTransport`, то есть копией в закрытый каталог приложения. Реальный HTTP/multipart backend пока не проверялся.
- Не проверены перезагрузка устройства, длительная офлайн-смена и нагрузка из проектного документа.
- На телефоне установлен крупный системный шрифт; это выявило и привело к исправлению компоновки кнопок камеры. Повторная визуальная проверка нижнего ряда после последнего изменения ещё нужна.
