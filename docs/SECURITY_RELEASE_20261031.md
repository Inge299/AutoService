# Пароли, сессии и release — 31.10.2026

Новые пароли сотрудников и клиентов, сброс и смена пароля требуют от 6 до 256
символов в API, Web и Android. Вход с уже существующим коротким паролем продолжает
работать; учётки и реальные пароли массово не меняются.

При самостоятельной смене пароля текущая bearer-сессия сохраняется. Все остальные
сессии этого пользователя отзываются, включая refresh; другие пользователи не
затрагиваются. При обращении через внутренний доверенный контекст без sessionId
отзываются все сессии пользователя. Изменение хеша, отзыв и аудит атомарны.
Сравнение с проверенным старым хешем не позволяет двум одновременным сменам
успешно заменить один и тот же старый пароль. Административный сброс по-прежнему
отзывает все сессии.

GitHub CI собирает release до merge на доверенных PR с уже настроенными signing
secrets и публикует app-release. Сам keystore и пароли не извлекаются из secrets.
Проверяются подпись, сертификат AutoService и отсутствие application-debuggable.
Сертификат: SHA256
`2d3fba77411b2b68d0cae37ca4582c8720de142923a8381353e0a7cd11949c93`.

Установленный на TECNO внутренний APK 105 имеет другой сертификат
`5cfc7eec9da4e638cad1ef9af89c7f6f4339ace63c64d8aafa6040acc146c288`.
Обычный install -r release поверх него не является допустимым обновлением.
Удалять установленное приложение/данные для смены подписи нельзя. Этот этап
готовит настоящий release для распространения и не выполняет миграцию подписей
существующего debug-канала. Подробности механизма:
[Android app signing](https://developer.android.com/tools/apksigner).

Интеграционный PR в main включает ранее проверенную цепочку до fda8771 и эти
исправления. Защита main требует одобрения другого разработчика, включая последний
push; обход или ослабление защиты не является частью выпуска.

## Дополнение: установка на старый debug-канал

После просьбы владельца установить release добавлен отдельный переходный APK
Android 9+ с проверенным public signing lineage. Обычный app-release Android 8+
сохраняется отдельным артефактом. Приватные ключи не переносятся между Mac/GitHub;
старый локальный ключ подписывает только подтверждение перехода к известному
публичному сертификату. Старому ключу оставлена только совместимость данных,
без signature-permissions, shared UID, authenticator и rollback. Подробности
и проверки: android/signing/README.md. Установка допускается только через
install -r, с контролем ID, SHA256 медиа, сессии, production signer и DEBUGGABLE.
