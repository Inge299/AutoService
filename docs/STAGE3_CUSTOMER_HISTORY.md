# Карточка клиента и очередь Android

Основа — коммит `28b07c1` (PR #56), развёрнутый на Mia. Следующая ветка сохраняет все изменения PR #54–56. Основная рабочая копия с изменениями второго разработчика не менялась.

В Web карточка открывается из клиентской базы и визита: контакты, все связанные автомобили с числом визитов, выбор машины, история и рекомендации опубликованных отчётов, отложенные работы с переходом в исходный визит. История и отложенные работы имеют независимые страницы по 20 записей и сохраняют выбранный автомобиль. Срок работы берётся из опубликованного отчёта и подписан как общий срок следующего визита; индивидуальные сроки и автоматическое сопоставление выполнений в последующих визитах этим этапом не добавляются.

API `/v1/customers/:id/history?page=1&futurePage=1&vehicleId=<uuid>` проверяет мастерскую клиента и принадлежность выбранного автомобиля. Неизвестные/чужие ID дают 404; некорректные параметры — 400. Старые записи без связи по customerId не объединяются по совпавшему телефону.

В Android добавлены поиск по имени, телефону, автомобилю и номеру; фильтры активных визитов, этапов, запроса звонка и отдельный архив. Телефоны нормализуются при поиске, номера учитывают кириллицу/латиницу и разделители, ё/е в имени эквивалентны. Известные запросы звонка выводятся выше обычных визитов. Запрос и фильтр сохраняются при возврате из визита; состояние разделяется по мастерским. Поиск работает по уже синхронизированным локальным данным. Новые ответы клиента появляются после обновления.

Схема PostgreSQL и Room не меняется. Редактирование/слияние клиентов и авто, физические медиа, пароли, отправка сообщений и платежи в этот этап не входят.

Проверки: Server typecheck/build, 135 тестов с настоящей PostgreSQL; Web lint/typecheck/build, 7 тестов; Android lint/unit/build. Интеграционные проверки покрывают 23 визита с одинаковой датой, независимые страницы отложенных работ, два автомобиля, чужую мастерскую с тем же телефоном и неверные параметры. Экранные тесты выполняются отдельно на TECNO. Визуальная проверка Web требует включённого управления браузером в Work.
