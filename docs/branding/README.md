# Эмблема AutoService

Эмблема — гаечный ключ внутри облачка сообщения. Основной цвет: `#0F6B78`, светлая часть: `#FFFFFF`.

- `emblem.svg` и `emblem.png` — бирюзовая эмблема на прозрачном фоне.
- `icon-preview.svg` и `icon-preview.png` — иконка для просмотра: белый знак на бирюзовом скруглённом фоне.
- `android-foreground.svg` и `android-foreground.png` — белый передний слой адаптивной иконки на прозрачном фоне. Знак размещён внутри безопасной области Android.
- `android-background.svg` и `android-background.png` — сплошной бирюзовый фоновый слой адаптивной иконки.

PNG-файлы имеют размер 1024 × 1024 пикселя. SVG можно масштабировать без потери качества. Для адаптивной иконки Android использовать отдельные foreground и background, а не скруглённый preview: форму иконки задаёт лаунчер. SVG содержат маску; при переводе в Android VectorDrawable её нужно заменить составным контуром или использовать подготовленные растровые слои нужных размеров.

В Android-приложении эмблема подключена:

- `@mipmap/ic_launcher` — адаптивная иконка в манифесте (обычная и круглая), отдельные белый foreground и бирюзовый background;
- `@drawable/ic_launcher_foreground` — векторный знак с исходным размещением в безопасной области; также используется для монохромной иконки Android 13+;
- `@drawable/ic_brand_emblem` — бирюзовая эмблема в заголовке входа и рабочего экрана;
- экран запуска Android 12+ использует адаптивную иконку;
- `@color/brand_primary` — основной цвет `#0F6B78`.

Маски SVG преобразованы в составные контуры VectorDrawable с `fillType="evenOdd"`.
Вырез ключа остаётся прозрачным. Скруглённый preview не используется как слой
адаптивной иконки: форму задаёт лаунчер. Старый знак автомобиля удалён.
