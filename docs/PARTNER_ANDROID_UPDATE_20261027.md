# Проверка обновления Android от партнёра — 27 октября 2026

Исходный коммит sirnapster88: `f06dbd14de8b4ae01a20b39a5c8a302059891b08`
из `codex/unified-ui`. Он интегрирован поверх безопасного main `691ead7`, а не
развёрнут из устаревшей ветки, отстающей на 14 коммитов.

## Изменения

- Очередь активных визитов и отдельный список завершённых/отменённых, сортировка
  по статусу и времени обновления.
- Следующий шаг в карточке визита, разделение активных и завершённых/отложенных находок.
- Кнопки с иконками, более компактные медиа-действия и обновлённые цвета/типографика.
- При разрешении конфликта сохранены поиск клиента и выбор его автомобиля,
  настройки смены пароля, отчёты, сроки и рекомендации по отложенным работам.

## Проверка и корректировки интеграции

- Убрано новое глобальное разрешение cleartext HTTP из debug-манифеста:
  установленное приложение использует HTTPS Mia, понижать транспортную защиту не нужно.
- Очередь вместе с шапкой прокручивается одной LazyColumn: при увеличенном шрифте
  список машин не оказывается за пределами экрана без возможности прокрутки.
- Новый синтетический экранный тест проверяет доступность активного и завершённого
  автомобиля при fontScale 2.0. Существующие тесты проверяют поиск, ошибку сети и отчёт.
- Сборка APK 100: lint, unit-тесты, debug APK и androidTest APK успешны.
- На разблокированном TECNO LK6 пройдены все 4 экранных теста без пропусков:
  обработка ошибки поиска, выбор второго автомобиля клиента с передачей в форму
  приёмки, отчёт со сроком отложенной работы, очередь при fontScale 2.0.
  Тесты используют синтетические данные, не создают записи в production.

## Mia и парольная политика

Изменения касаются только Android; API, Web, Prisma и compose не отличаются от
production main `691ead7`. Mia уже содержит совместимую серверную часть;
перезапускать контейнеры или менять БД ради этого обновления не требуется.
PR #53 с паролями от пяти символов не включён: он остаётся отдельным изменением.
Пароли и пользовательские записи при установке APK не меняются.
